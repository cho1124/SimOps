# 시스템 기획

상태: 초안

## 게임 개요

- 장르: 턴제 미니 로그라이크
- 세션: 일반 전투 5회와 보스 전투 1회
- 전투 사이: 보상 3개 중 하나 선택
- 종료: 보스 클리어 또는 플레이어 사망
- 플레이 주체: 사람 또는 합성 플레이어
- 경쟁: 실시간 멀티플레이 없이 시즌 기반 비동기 랭킹 제공

## 핵심 플레이 루프

```text
시즌·캐릭터 선택
→ Run 시작
→ 전투 상황 관찰
→ 행동 선택
→ 전투 종료
→ 보상 선택
→ 다음 스테이지
→ 보스 또는 사망
→ 서버 검증
→ 점수·랭킹·분석 반영
```

## 전투 시스템 초안

### 기본 상태

- 플레이어: 체력, 최대 체력, 공격력, 방어력, 에너지, 상태 효과
- 적: 체력, 공격력, 행동 예고, 상태 효과
- Run: 현재 스테이지, 턴, 보유 보상, 점수, 시드

### 기본 행동 후보

- 기본 공격
- 방어
- 스킬 사용
- 아이템 사용

행동마다 비용, 대상, 효과, 사용 조건이 필요하다. 구체적인 수치와 턴 규칙은 다음 시스템 기획 논의에서 확정한다.

## 성장과 보상 초안

전투 종료 후 세 가지 후보에서 하나를 선택한다.

- 공격 성장: 공격력, 치명타, 조건부 추가 피해
- 방어 성장: 방어력, 보호막, 피해 감소
- 생존 성장: 체력 회복, 최대 체력, 지속 회복
- 유틸리티: 에너지, 행동 비용 감소, 상태 효과

보상 조합에 따라 플레이 스타일 차이가 나타나야 하며, 하나의 필수 선택으로 수렴하지 않아야 한다.

## 합성 플레이어

MVP의 합성 플레이어는 모두 동일한 `GameObservation`과 행동 목록을 사용한다.

| 유형 | 목적 | 예상 행동 |
|---|---|---|
| Random | 기준선 | 유효 행동 중 무작위 선택 |
| Novice | 초보자 근사 | 단기적이고 일부 비효율적인 선택 |
| Aggressive | 공격 선호 | 피해량과 공격 보상 우선 |
| Defensive | 안정성 선호 | 방어, 회복, 생존 보상 우선 |
| Greedy | 단기 최적화 | 현재 턴 기대값이 높은 행동 우선 |
| Explorer | 다양성 탐색 | 덜 사용한 행동과 보상 조합 선호 |

각 에이전트는 버전과 파라미터를 가져야 한다. 합성 페르소나는 실제 인간 유형과 동일하다고 표현하지 않는다.

## 점수와 랭킹

### 랭킹 분리

- 인간 플레이어 공개 랭킹
- 합성 플레이어 벤치마크
- 인간과 합성 플레이어의 분포 비교 화면

합성 플레이어는 인간 공개 랭킹에 등록하지 않는다.

### 점수 구성 후보

- 도달 스테이지
- 처치 및 전투 성과
- 남은 체력
- 사용 턴 효율
- 보스 클리어 보너스

점수 공식은 `ScoreRuleVersion`으로 관리한다. 정확한 공식은 게임 수치와 함께 확정한다.

### 서버 검증

클라이언트가 최종 점수를 제출하지 않는다. 시드와 행동 기록을 제출하고, 서버가 동일한 게임 규칙으로 재실행하여 결과와 점수를 계산한다.

### 시즌

시즌은 다음 버전을 고정한다.

- Game Version
- Config Version 범위
- Score Rule Version
- 시작·종료 시각

점수에 큰 영향을 주는 변경은 새 시즌이나 별도 랭킹으로 분리한다.

## LiveOps 기능

### 변경 가능한 항목 후보

- 플레이어와 적 기본 수치
- 스테이지별 난도 배율
- 적 행동 패턴 파라미터
- 보상 출현 확률과 수치
- 점수 규칙
- 시즌 기간
- 실험 Variant 배정 비율

### 설정 상태

```text
Draft → Validated → Simulated → Approved → Published
                                      ↓
                                  Rolled Back
```

MVP에서 AI는 변경안을 제안할 수 있지만 승인과 배포는 사람이 담당한다.

## 사용자 흐름

### 플레이어

```text
익명 계정 생성
→ 닉네임 설정
→ 게임 플레이
→ 결과 검증
→ 랭킹 확인
→ 기록 또는 리플레이 확인
```

### 운영자

```text
실험 가설 작성
→ 설정 Variant 생성
→ 합성 플레이어 구성
→ 대량 시뮬레이션 실행
→ 지표·AI 분석 확인
→ 승인 또는 수정
→ 설정 배포
→ 인간 플레이 결과 관찰
```

## MVP 포함 범위

- 한 개 캐릭터 또는 최소한의 캐릭터 차이
- 일반 적 3종과 보스 1종
- 일반 전투 5회와 보스 1회
- 선택 가능한 보상 풀
- 규칙 기반 합성 플레이어 최소 5종
- Headless 대량 실행
- 두 설정 Variant 비교
- 텔레메트리와 웹 대시보드
- 익명 사용자와 시즌 랭킹
- 행동 로그 기반 서버 검증
- AI 실험 결과 요약
- 설정 승인, 배포, 롤백

## MVP 제외 범위

- 실시간 멀티플레이
- 실시간 액션 조작
- 상용 수준의 콘텐츠 양
- 결제와 수익화
- 친구·길드·채팅
- 완전 자율 운영 배포
- 처음부터 강화학습 적용
- 실제 인간 행동 예측 성능 주장
