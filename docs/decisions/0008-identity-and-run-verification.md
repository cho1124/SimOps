# ADR-0008: 사용자 식별과 인간 Run 검증

상태: 제안

연결 워크숍: [Workshop-0007](../workshops/0007-auth-and-run-verification.md)

## 고려한 선택지

- 익명 Credential + Ticket + 전체 Replay
- 정식 계정 + Ticket + 전체 Replay
- 익명 ID + Client Result 검사

## 결정

사용자 결정 대기.

## 결과와 포기한 것

공격 입력 Spike 이후 작성한다.

## 재검토 조건

선택 시 계정 복구와 안티치트 Trigger를 정의한다.
