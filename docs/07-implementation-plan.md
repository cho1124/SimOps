# 구현 계획

상태: 사전 초안

구현은 레이어를 모두 만든 뒤 연결하는 방식이 아니라, 작동하는 수직 단면을 순차적으로 확장한다.

## 마일스톤 0: 설계 기준선

- 프로젝트 정의 확정
- 시스템 기획 확정
- 첫 실험과 지표 확정
- 아키텍처와 기술 스택 ADR 확정
- 데이터와 인터페이스 초안 확정

완료 데모: 문서만으로 첫 실험의 입력, 실행, 출력이 설명된다.

## 마일스톤 1: 결정론적 게임 코어

- 순수 C# 게임 상태와 행동
- 전투와 보상 선택
- 시드 기반 난수
- 콘솔에서 한 Run 실행
- 동일 입력 재현 테스트

완료 데모: 같은 시드와 행동 로그가 항상 같은 결과를 만든다.

## 마일스톤 2: Unity 플레이와 리플레이

- Unity 표현 계층
- 사람 입력
- 행동 로그 생성
- 저장된 Run 리플레이

완료 데모: 사람의 플레이를 저장하고 동일하게 재생한다.

## 마일스톤 3: 합성 플레이어

- 공통 Agent 계약
- 규칙 기반 에이전트 최소 5종
- Headless 반복 실행
- 페르소나별 선택 분포 확인

완료 데모: 같은 상황에서 에이전트 성향에 따라 다른 선택 경향이 나타난다.

## 마일스톤 4: 백엔드와 데이터

- Run과 이벤트 수집 API
- PostgreSQL 저장
- 버전과 시드 추적
- 행동 로그 기반 서버 검증

완료 데모: 제출한 Run을 서버가 재실행해 유효성을 판정한다.

## 마일스톤 5: 랭킹

- 익명 사용자와 닉네임
- 시즌과 점수 규칙
- 전체 및 내 주변 랭킹
- 인간과 합성 플레이어 분리

완료 데모: 검증된 인간 Run만 시즌 랭킹에 반영된다.

## 마일스톤 6: 실험 대시보드

- 실험과 Variant 관리
- 대량 실행 요청
- 핵심 지표 비교
- 설정 상태와 승인 흐름

완료 데모: A/B 시뮬레이션 결과를 대시보드에서 비교한다.

## 마일스톤 7: AI 분석가

- 계산된 지표를 도구로 제공
- 변화 요약
- 원인 가설과 다음 실험 제안
- 근거 지표 표시

완료 데모: AI가 임의 수치를 생성하지 않고 실험 결과를 설명한다.

## 마일스톤 8: LiveOps 폐루프

- 승인된 설정 배포
- Unity와 Runner 설정 동기화
- 롤백
- 변경 후 재실험

완료 데모: 가설부터 변경 검증까지 하나의 흐름으로 실행된다.

## MVP 이후

- ML-Agents 또는 별도 강화학습 에이전트
- 인간 로그 기반 페르소나 보정
- 자동 QA와 도달 가능성 탐색
- 게임 경제 시뮬레이션
- 범용 Unity SDK 추출
- 여러 게임 프로젝트 지원
