# 설계 문서 안내

## 문서 상태

각 문서는 다음 상태 중 하나를 사용한다.

- `초안`: 방향만 작성됐으며 논의가 필요하다.
- `검토 중`: 주요 선택지를 비교하고 있다.
- `확정`: 현재 구현 기준으로 사용한다.
- `변경 예정`: 새로운 결정으로 수정이 필요하다.

문서에 적힌 내용과 ADR이 충돌하면 최신 ADR을 우선한다.

## 진행 규칙

1. 한 번에 한 단계의 문서만 확정한다.
2. 다음 단계에서 앞 단계의 문제를 발견하면 이전 문서를 수정한다.
3. 중요한 결정은 선택 이유, 포기한 것, 재검토 조건을 함께 기록한다.
4. 측정하지 못하는 성공 조건은 사용하지 않는다.
5. 구현 전에 MVP와 제외 범위를 고정한다.
6. 합성 데이터와 실제 사용자 데이터를 모든 화면과 분석에서 구분한다.
