# 프로젝트 정의

상태: 확정

## 한 문장 정의

SimOps는 Unity 게임을 합성 플레이어가 반복 플레이하고, 밸런스 가설을 측정·비교한 뒤 승인된 설정을 안전하게 반영하는 개발자용 LiveOps 실험 플랫폼이다.

## 제품의 중심

SimOps의 주인공은 기준 게임 자체가 아니라 `게임 개발자가 운영 가설을 검증하는 과정`이다.

- 기준 게임은 플랫폼의 기능을 검증하는 reference implementation이다.
- 게임의 콘텐츠 양보다 실험 가능성, 결정론, 재현성을 우선한다.
- Unity 전문성을 중심으로 백엔드, 데이터, 웹, AI, 운영 역량을 연결한다.
- 장기적으로 다른 Unity 게임이 Game Core와 Agent 계약을 구현해 연결할 수 있는 구조를 지향한다.

## 해결하려는 문제

출시 전 또는 사용자가 적은 게임에서는 다음 문제가 있다.

- 밸런스 데이터를 얻기 위한 반복 플레이테스트 비용이 크다.
- 여러 플레이 성향에서 변경 영향을 비교하기 어렵다.
- 밸런스 변경의 회귀와 극단적인 전략을 수동으로 탐색하기 어렵다.
- 플레이테스트, 데이터 분석, 설정 변경, 재검증 과정이 분리되어 있다.
- AI가 제안한 분석이나 변경안을 검증 없이 신뢰하기 어렵다.

## 핵심 사용자

### 1. 게임 개발자·기획자·LiveOps 운영자

가장 중요한 사용자다.

- 밸런스 가설과 성공 기준을 정의한다.
- 설정 Variant와 합성 플레이어 집단을 구성한다.
- 대량 시뮬레이션 결과를 성향별로 비교한다.
- 문제가 발생한 Run을 같은 시드와 행동으로 재현한다.
- AI가 제시한 해석과 다음 실험안을 근거 지표와 함께 검토한다.
- 검증된 설정을 승인·배포하거나 이전 설정으로 롤백한다.

### 2. 게임 플레이어

- 짧은 턴제 로그라이크를 플레이한다.
- 검증된 기록을 시즌 랭킹에 등록한다.
- 자신의 빌드, 점수, 리플레이를 확인한다.
- 실제 플레이 데이터로 합성 플레이어와의 차이를 관찰할 수 있게 한다.

### 3. 기술 평가자와 오픈소스 사용자

- Unity부터 시뮬레이션, 서버 검증, 데이터, 웹, AI까지 연결된 흐름을 확인한다.
- 설계 결정과 실험 결과를 재현한다.
- 향후 자신의 Unity 게임에 일부 계약과 도구를 적용할 수 있다.

## 핵심 사용자 여정

```text
운영자가 밸런스 문제와 가설 정의
→ Control과 Treatment 설정 생성
→ 합성 플레이어로 paired simulation 실행
→ 결과·가드레일·실패 리플레이 확인
→ AI 분석가의 근거 기반 설명 검토
→ 운영자가 설정 승인
→ 새 공개 설정으로 배포
→ 인간 플레이와 랭킹 데이터 관찰
→ 합성·인간 데이터 차이를 다음 실험에 반영
```

## MVP가 제공하는 가치

- 동일한 Game Core를 사람, 규칙 기반 에이전트, 서버 검증기가 공유한다.
- 동일 시드 집합으로 여러 설정을 공정하게 비교한다.
- 플레이 성향별로 난도, 효율, 선택 다양성의 차이를 보여준다.
- 사람의 점수 제출을 행동 로그 재실행으로 검증한다.
- AI는 계산된 결과만 해석하며 직접 배포하지 못한다.
- 설정 변경의 초안, 검증, 승인, 배포, 롤백 이력을 남긴다.

## MVP 성공 조건

### 제품 흐름

- Control과 두 Treatment를 하나의 실험으로 실행할 수 있다.
- 여섯 종류의 합성 플레이어가 구분되는 행동 분포를 보인다.
- 실험 결과에서 성향별 클리어율, 실패 구간, 효율, 선택 다양성을 비교할 수 있다.
- 운영자가 결과를 확인하고 한 설정을 승인·배포·롤백할 수 있다.

### 정확성과 재현성

- 동일한 게임 버전, 설정 버전, 시드, 행동 로그는 동일한 결과를 생성한다.
- MVP 검증 세트에서 클라이언트와 서버 재실행 결과 불일치가 0건이다.
- 인간 랭킹에는 서버에서 검증된 Run만 반영된다.
- 합성 플레이와 인간 플레이 데이터가 명확하게 분리된다.

### 포트폴리오

- 가설부터 재실험까지 전체 폐루프를 3분 이내 데모로 보여줄 수 있다.
- 주요 설계 선택, 트레이드오프, 실험 결과를 문서로 설명할 수 있다.
- 합성 데이터의 가능성과 한계를 함께 제시한다.

## 주장하지 않는 것

- 합성 플레이어가 실제 인간 행동을 완전히 예측한다.
- 합성 데이터만으로 리텐션, 매출, 상업적 성공을 예측한다.
- 성향 이름이 실제 사용자 집단을 정확히 대표한다.
- AI가 사람의 게임 디자인 판단을 대체한다.
- 합성 실험이 실제 사용자 대상 통계 실험과 동일하다.
- MVP가 모든 Unity 장르를 지원하는 범용 제품이다.

## MVP 제외 범위

- 실시간 멀티플레이
- 실시간 액션 조작
- 결제, 광고, 수익화 최적화
- 친구, 길드, 채팅
- 장기 리텐션과 이탈 예측
- AI의 무승인 설정 배포
- 강화학습 에이전트
- 상용 게임 수준의 콘텐츠 양과 아트 완성도
- 다중 게임 프로젝트 지원

## 첫 번째 대표 데모

> 여섯 번의 전투로 구성된 기준 게임에서 여섯 종류의 합성 플레이어가 Control과 두 Treatment를 동일 시드로 Cell당 1,000회, 총 18,000회 플레이한다. 운영 대시보드는 중반 난도, 전체 클리어율, 행동·보상 다양성을 비교하고 AI 분석가는 근거 지표와 함께 다음 변경안을 제안한다. 운영자가 설정을 승인하면 Unity 클라이언트에 반영되고, 이후 인간 플레이는 서버 검증 후 시즌 랭킹에 등록된다.

## 제품 원칙

1. 실제 사용자 예측보다 사전 검증과 회귀 탐색을 우선한다.
2. 한 번의 완전한 실험 폐루프를 기능 수보다 우선한다.
3. 결과보다 재현 가능한 근거를 우선한다.
4. 합성 데이터와 인간 데이터를 섞어 표현하지 않는다.
5. 설정과 분석에 버전과 감사 이력을 남긴다.
6. AI의 제안, 시스템의 계산, 사람의 승인을 분리한다.

## MVP 이후의 제품 방향

- 인간 플레이 로그를 이용한 페르소나 파라미터 보정
- ML-Agents 또는 별도 강화학습 에이전트
- 게임 경제와 장기 진행 시뮬레이션
- 자동 QA, 도달 가능성, 악용 전략 탐색
- 게임별 Adapter와 Unity SDK 추출
- 여러 게임과 팀을 지원하는 운영 플랫폼
