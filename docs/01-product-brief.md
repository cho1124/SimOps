# 프로젝트 정의

상태: 초안

## 한 문장 정의

SimOps는 Unity 게임에 합성 플레이어를 투입해 밸런스 가설을 반복 실험하고, 그 결과를 LiveOps 설정으로 안전하게 반영하는 개발자용 실험 플랫폼이다.

## 해결하려는 문제

소규모 개발이나 출시 전 단계에서는 다음 문제가 있다.

- 실제 사용자가 없거나 충분하지 않아 밸런스 데이터를 얻기 어렵다.
- 반복 플레이테스트 비용이 크다.
- 밸런스 변경의 영향을 여러 플레이 성향에서 비교하기 어렵다.
- 플레이테스트, 분석, 설정 변경 과정이 서로 분리돼 있다.
- AI가 제안한 결과를 검증 없이 신뢰하기 어렵다.

## 핵심 사용자

### 게임 개발자·기획자

- 밸런스 가설을 대량 시뮬레이션으로 사전 검증한다.
- 플레이 성향별 결과 차이를 확인한다.
- 변경안을 실제 플레이에 적용하기 전에 비교한다.
- 문제가 발생한 플레이를 같은 시드로 재현한다.

### 게임 플레이어

- 짧은 턴제 로그라이크를 플레이한다.
- 시즌 랭킹에서 다른 사람과 비동기적으로 경쟁한다.
- 자신의 빌드와 기록을 확인한다.

### 포트폴리오 관람자·기술 평가자

- Unity 클라이언트부터 시뮬레이션, 백엔드, 데이터, 웹, AI까지 연결된 전체 흐름을 확인한다.
- 설계 결정과 검증 결과를 재현 가능한 형태로 확인한다.

## 제공 가치

- 실제 서비스가 없어도 운영 실험 파이프라인을 검증할 수 있다.
- 동일 게임 규칙을 사람과 여러 합성 플레이어가 공유한다.
- 밸런스 설정 A/B를 반복 가능한 조건에서 비교한다.
- AI는 분석과 가설 제안을 돕고, 계산과 배포 권한은 통제한다.
- 인간 플레이 결과와 합성 플레이 결과의 차이를 관찰할 수 있다.

## 주장하지 않는 것

- 합성 플레이어가 실제 인간 행동을 완전히 예측한다.
- 합성 데이터만으로 상업적 성공이나 리텐션을 예측한다.
- AI가 사람의 게임 디자인 판단을 대체한다.
- 자동 실험 결과가 통계적으로 실제 사용자 A/B 테스트와 동일하다.
- 첫 버전이 범용적인 모든 Unity 장르를 지원한다.

## 첫 번째 데모

> 성향이 다른 합성 플레이어 다섯 종류가 두 가지 밸런스 설정을 각각 1,000회 플레이하고, 대시보드가 클리어율·난도 곡선·선택 다양성을 비교하여 다음 실험안을 제안한다.

## 미결정 사항

- 공개 대상: 개인 포트폴리오 우선인지 범용 오픈소스 SDK 우선인지
- 배포 대상 플랫폼: PC/WebGL 중 MVP 우선순위
- 실제 외부 플레이어 모집 범위
- 프로젝트 최종 명칭과 브랜딩
